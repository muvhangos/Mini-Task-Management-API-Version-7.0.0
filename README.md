# Mini Task Management API
**Version 7.0.0**

🚀 **Live API - Test It Now:** https://mini-task-management-api-version-7-0-0.onrender.com/docs
📦 **GitHub:** https://github.com/muvhangos/Mini-Task-Management-API-Version-7.0.0

A RESTful Task Management API built with Python and FastAPI. This project provides endpoints for creating, retrieving, updating, and deleting tasks, with persistent storage using SQLite.

## Features
- Create new tasks
- Retrieve all tasks
- Retrieve tasks by ID
- Update existing tasks
- Delete tasks
- SQLite database persistence
- SQLAlchemy database integration
- Pydantic data validation (Title 3-100 chars, Description 5-500 chars)
- RESTful API endpoints
- Interactive Swagger documentation

## Quick Test (No Install Needed)
1. Open Live Docs link above
2. POST /tasks -> Try it out -> Create a task
3. GET /tasks -> See all tasks
